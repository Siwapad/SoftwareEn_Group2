## Overview

Retrospective นี้ใช้รูปแบบ **Sailboat** (เรือใบ) โดยจินตนาการว่าโปรเจกต์คือเรือที่แล่นมุ่งสู่เกาะซึ่งเป็นเป้าหมายของทีม แต่ละหัวข้อสะท้อนปัจจัยที่ส่งผลต่อการเดินทาง ทั้งแรงหนุน แรงต้าน ความเสี่ยง และสิ่งที่ทีมต้องการพิชิต

## Boosts — แรงลมที่ช่วยเร่งเรือ

> _What will help your project move faster?_

สิ่งที่ช่วยให้ทีมทำงานได้เร็วและราบรื่นขึ้น:

- **Sprint 1 กับ 2** — กลุ่มแบ่งหน้าที่มา 3 Sprint สุดท้ายเป็นหัวหน้าที่งานสวยงามดูดี _(Siwapat Phornon)_
- **Sprint 12** — คืนสมองมีงองค้องต้องทำงาน _(Kaewpatcharat Sisan)_
- **Sprint 2** — อาจารย์พูดอยู่โต้โต _(Kaewpatcharat Sisan)_

## Delays — สิ่งที่ทำให้เรือช้าลง

> _What blockers might slow down your project from shipping at the right time?_

อุปสรรคและปัญหาที่ทำให้งานล่าช้า:

- **ต้องจัดเซิร์ฟเวอร์ Domain และ Domain อีกไม่ได้** Static ไหม _(Kaewpatcharat Sisan)_
- **แค่ก็ได้** _(noted)_
- **ทำงานเป็นไป 1 ปีก** _(Fakkapon D. Sangprom — 3,000 THB, MARINE)_
- **เพื่อน Oumsima 1** _(Paloma Oumsima)_

## Risks — หินโสโครกใต้น้ำ

> _What issues might block your project from sailing smoothly?_

ความเสี่ยงที่อาจทำให้โปรเจกต์สะดุด:

- **Requirements ไม่ครบ**
- **ทำเอกสารเสื่อมไม่กัน**
- **ผิดที่คิดว่า Agile เป็น Code** — ความเข้าใจผิดเกี่ยวกับ Agile framework
- **Scenario ที่ไม่คาดคิด**
- **Sprint! — ด้วย Agile เป็น Code และ ไม่ใช่ทำ .doc**
- **นามวิธีมั่น** ที่รู้ปัจจุบันออนไลน์

- **ความสำเร็จในการใช้ App** _(Kaewpatcharat Sisan)_

- **ความโดยสมัยส่วนตัวที่มีผู้ใช้ที่เหมาะกว่าตอนสาย** _(Siwapat Phornon)_
- **เรียนรู้การทำงานแบบ AGILE แบบ Scrum** _(noted)_

## Action Items จาก Retrospective

จากการวิเคราะห์ board ข้างต้น ทีมควรดำเนินการดังนี้:

- [✓] จัดทำ Requirements ให้ครบและชัดเจนก่อนเริ่ม Sprint ถัดไป

### Keep Doing
- [✓] รักษาจังหวะการทำงานแบบ Sprint ต่อเนื่อง
- [✓] ใช้ Agile Scrum framework อย่างสม่ำเสมอ

## Retrospective Format Reference

```
Sailboat Retrospective
├── ⛵ Boosts    → สิ่งที่เร่งให้เรือแล่นเร็ว (ปัจจัยบวก)
├── ⚓ Delays    → สิ่งที่ดึงให้เรือช้าลง (blockers)
├── ⚠️ Risks     → หินโสโครกใต้น้ำ (ความเสี่ยง)
└── 🏝️ Goals     → เกาะที่เป็นเป้าหมาย (สิ่งที่ต้องการบรรลุ)
```
